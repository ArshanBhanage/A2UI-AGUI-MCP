# 03.3 A2UI Lit and AG-UI

This lesson separates A2UI representation from AG-UI transport by carrying a validated A2UI message in a custom AG-UI event. The offline bridge is tested; the official Lit renderer is blocked until its current package and a visual host are configured, so this lesson does not claim renderer success. Run `python3 -m pytest test_bridge.py` and `python3 demo.py`.
