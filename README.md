## Demonstration scope

The current examples primarily exercise small offline adapters. Official renderer execution, model-backed agent loops, and visual MCP host integration remain incomplete. TrueForge's agent-list API has responded successfully; a model turn has not been verified.

The combined video provides a preliminary review of the existing examples. Complete instructional walkthroughs remain outstanding.
